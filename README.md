# 觀光飯店經營評估試算工具

一般用途的觀光地區飯店／旅館財務可行性試算工具，不是特定飯店的企劃書。把「房間數 → 淡旺季住房率 × 房價 → 營收 → 成本 → 淨利」拆成可調整的變數，逐月試算損益，算出損益兩平住房率、RevPAR 與回本年數。

- 純前端單頁網站，無需安裝、無後端、無序號授權。
- 客房格狀圖：每格一間房，切換月份與平日／假日，看那一晚賣出幾間、營收多少。
- 12 個月損益長條圖：一眼看出哪幾個淡季月份虧損、要靠旺季現金撐多久。
- 淡旺季月曆可逐月自訂（旺季／平季／淡季）。
- 6 種觀光飯店型態範例（海濱度假／溫泉／山林景觀小旅店／離島／古城觀光商旅／親子度假），各自套用對應的房價、住房率、淡旺季月曆與人事編制。
- 選填 Claude／OpenAI／Gemini／OpenRouter API 金鑰（BYOK，只存瀏覽器 localStorage）做 AI 診斷；沒有金鑰會自動改用規則式健檢。
- 可匯出 PDF（含浮水印）、加入主畫面安裝成 App；完整說明見 [`manual.html`](./manual.html)。
